\section{RESEARCH EXPERIENCE}

\cvheading{Research Assistant}{Feb 2026 -- Present}{Yale University (Prof. Mengxia Liu's Group)}{New Haven, CT}
\begin{cvitemize}
    \item Built a joint spectro-polarimetric forward model that recovers a 324-channel datacube (spatial $\times$ 81 wavelength bands $\times$ 4 Stokes parameters) from a single multiplexed lensless speckle image.
    \item Formulated the reconstruction as a conic-constrained inverse problem, enforcing a Lorentz-cone constraint on the Stokes vector ($S_0 \geq \|S_{1:3}\|$) to guarantee physically admissible polarization states.
    \item Implemented a consensus ADMM solver in PyTorch with an exact joint proximal operator encoding the physical constraints, $L_1$ spectral sparsity, and Sherman--Morrison linear solves; runs on GPU via SLURM.
    \item Calibrated PSF libraries with Gram--Schmidt orthogonalization to remove channel cross-talk and performed spectral unmixing via non-negative least squares.
\end{cvitemize}

\cvheading{Research Assistant}{Apr 2026 -- Present}{UVA BAL Lab (Prof. Xin Cynthia Tong's Group)}{Charlottesville, VA}
\begin{cvitemize}
    \item Developed PRISM, a constrained-projection framework for multivariate longitudinal missing-data imputation that projects initial imputations toward the model-implied covariance structure, correcting the variance attenuation of standard conditional-expectation methods.
    \item Built the solver in C++17 (RcppArmadillo) with projected gradient descent, Armijo line search, exact mean-constraint projection, and KKT optimality checks.
    \item Tested the framework on multi-qubit state tomography: the random-forest estimator did not transfer, while the constrained-projection layer did, demonstrating the value of the projection structure.
\end{cvitemize}

\cvheading{Research Assistant}{Oct 2025 -- Present}{UVA (Prof. Liqin Ke's Group)}{Charlottesville, VA}
